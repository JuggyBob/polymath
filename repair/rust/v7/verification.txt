Fault audit
-----------
Method: two counterfactual experiments per hunk. INJECT = golden source with
only that hunk's faulty text, run against the full 45+49 suite; REVERT = task
source with only that hunk restored. A hunk is observable if an isolated inject
flips at least one TEST line, or (for perf-only hunks) flips a perf gate.
The audit used a temporary merged driver running both suites with perf disabled
for correctness experiments, and the unmodified hidden driver for perf ones.

Result: 45 original hunks audited. 4 hunks (3 logical edits) were permanently
invisible and were corrected in task/:
  - compiler.rs slot_of: HashMap::get replaced by a linear scan (hunks 1-2).
    No test with enough slots exists; compile time is unchanged on all tests.
  - opcode.rs disassemble_block: String::with_capacity removed (hunk 15).
    perf_disasm median 3.8 ms without it, 3.9 ms with it; gate is 50 ms.
  - snapshot.rs put_u32: extend replaced by whole-buffer copy (hunk 26).
    perf_snapshot median 1.47 ms vs 0.19 ms; gate is 60 ms.
All 41 remaining hunks are observable: 39 flip at least one correctness test
when injected into golden; 2 are perf-only and flip a gate:
  - opcode.rs disassemble_block format! accumulation (hunk 16):
    perf_disasm 201.57 ms FAIL when injected, 3.84 ms PASS when reverted.
  - vm.rs Print quadratic output accumulation (hunk 45):
    perf_print 578.44 ms FAIL when injected, PASS when reverted.
Masked hunks are allowed and terminate: e.g. the compiler Ge operand swap is
masked by the lexer/parser >= faults; the raw-bytecode SPAWN/JOIN/YIELD
deserialization gap is masked by the DISTINCT mnemonic fault; array identity
equality is masked by "Distinct always true"; the snapshot ready-queue loss is
masked by the host run() and snapshot magic faults; the duplicate-fiber check
is masked by the checksum-seed fault. Each becomes observable once its
prerequisite fixes are applied, as the isolated-injection results confirm.
No permanently invisible fault remains.
