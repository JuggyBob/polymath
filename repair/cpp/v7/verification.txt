Planted fault audit (new)
-------------------------
Single-fault injection audit: each planted fault was injected alone into a copy
of the golden sources and compiled with a combined harness running all 45
visible + 49 hidden tests + 3 perf workloads (94 TEST + 6 PERF lines).
  43 documented textual faults form 41 logical faults (two coupled pairs:
  the Value copy-ctor declaration+definition and the snapshot static-leak
  declarations+uses).
  Before coverage work: 28 observable, 13 invisible.
  After coverage work: 41/41 observable, 0 permanently invisible.
Coverage added in the hidden suite without changing the 49 test names:
  '#' inside a string; Ge/Ne lexer token kinds; compile_source global indices;
  from_source name accumulation; run() cache hit; bool tag in a snapshot;
  >32-bit int in a snapshot; cross-restore stale globals; hex_encode leading
  nibble; FNV-1a operation order; GET/SET index vs name lookup; JOIN on a
  halted target. The task build.cpp run-cache fault now appends "\n" on a
  cache hit so the repeated-run check detects it.
Chains terminate: GE (lexer token -> parser node -> compiler opcode), fibers
(SPAWN -> YIELD rotation -> JOIN halted target), snapshot (checksum range ->
wide ints/bool tags -> static leak), arrays (APUSH copy -> deep-copy alias ->
DISTINCT identity). Each chain reaches the golden with no cycles; every fault
has at least one visible or hidden test that fails in isolation.

Scorer protocol check
---------------------
Each correctness test emits exactly one "TEST <name> PASS|FAIL" line; each
performance workload emits exactly three "PERF <name> <ms> PASS|FAIL" lines.
A PERF FAIL does not set score_zero (verified with the task score.json).
